# Audience Quiz · The Ventilator Games

ระบบให้ผู้ชมร่วมตอบคำถามแบบพิมพ์คำตอบผ่านมือถือ (สไตล์ Kahoot) แยกจากระบบเกมบนเวที

- ผู้ชมสแกน QR → ใส่ชื่อ + สถาบัน → ตอบคำถามที่ Host เปิด (ส่งได้ครั้งเดียวต่อข้อ)
- คะแนนต่อข้อ: ตอบถูกได้ 500–1,000 ตามความเร็ว (ตอบทันทีได้ 1,000, ตอบตอนหมดเวลาได้ 500) ตอบผิดได้ 0
- รางวัลรายข้อ: ผู้ตอบถูกเร็วที่สุด (ตั้งค่าได้ว่า 1 คนรับได้ครั้งเดียว)
- รางวัลรวม: คะแนนรวมสูงสุด 3 อันดับ (ถ้าคะแนนเท่ากัน คนที่ใช้เวลารวมน้อยกว่าชนะ)
- เวลาตอบใช้เวลาของเซิร์ฟเวอร์ ไม่ใช่เวลาของมือถือ

## หน้าต่าง ๆ

| หน้า | ใช้โดย | PIN |
|---|---|---|
| `index.html` | ผู้ชม (มือถือ) | – |
| `screen.html` | จอหลัก / projector | – |
| `host.html` | ผู้ควบคุม: คลังโจทย์, เปิดคำถาม, ตรวจคำตอบ, ประกาศผล, export | ✓ (PIN เดียวกับระบบเกมบนเวที) |

## ระหว่างเกม (Host)

1. เลือกโจทย์ทางซ้ายให้ตรงกับข้อที่ทีมบนเวทีเลือก → **เปิดคำถาม**
2. ระบบนับถอยหลังและปิดรับเอง (หรือกด **ปิดรับคำตอบเลย** / **+10 วิ**)
3. ช่องขวาจัดกลุ่มคำตอบที่เหมือนกันให้ (ไม่สนตัวพิมพ์ ช่องว่าง เครื่องหมาย และสะกดผิด 1–2 ตัวในคำยาว)
   กด ✓/✗ ที่กลุ่มเพื่อตัดสินเอง หรือเพิ่มคำตอบที่ยอมรับเพิ่มได้ทันที
4. **เฉลยบนจอ** → จอใหญ่ขึ้นคำเฉลย + ผู้ตอบถูกเร็วที่สุด + 5 อันดับแรก มือถือแต่ละคนเห็นคะแนนของตัวเอง
5. **แสดงตารางคะแนน** หรือ **กลับหน้ารอ** แล้วเลือกข้อถัดไป
6. จบเกม: กด **รางวัลรายข้อ → อันดับ 3 → อันดับ 2 → อันดับ 1**

ถ้าตัดสินผิดหลังเฉลยแล้ว แก้ ✓/✗ ได้เลย คะแนนและอันดับจะคำนวณใหม่ให้เอง (แท็บผลคะแนน → **ตรวจใหม่** สำหรับข้อก่อนหน้า)

## นำเข้าโจทย์

- **จากข้อความ**: เว้น 1 บรรทัดระหว่างข้อ

  ```
  ผู้ป่วย ARDS ควรตั้ง tidal volume กี่ mL/kg PBW
  ตอบ: 6, 6 mL/kg, หก
  เฉลย: 6 mL/kg PBW
  ป้าย: Setting 10
  เวลา: 30
  ```
  หรือบรรทัดเดียว `โจทย์ | คำตอบ1, คำตอบ2`
- **จากภาพ**: กด "นำเข้าภาพ" หรือลากไฟล์มาวาง (1 ภาพ = 1 ข้อ) แล้วกดแก้ไขเพื่อใส่คำตอบ · ในหน้าต่างแก้ไขกด Ctrl/⌘+V วางภาพจากคลิปบอร์ดได้
- **ไฟล์สำรอง (.json)**: ดาวน์โหลด/นำเข้าคลังทั้งชุดพร้อมภาพ ใช้ย้ายโจทย์จากเครื่องทดสอบไปเครื่องจริง

โจทย์และคำตอบเก็บใน Firestore (เฉพาะทีมงานอ่านได้) ผู้ชมเห็นโจทย์เฉพาะตอนที่เปิดแล้ว และเห็นคำเฉลยเฉพาะตอนเฉลย

## ติดตั้ง

ใช้ Firebase project เดิม (`ventilator-night-out`) และ PIN ทีมงานเดิม

1. Firebase Console → Firestore → Rules → วางเนื้อหา `../firestore.rules` (ไฟล์ที่ root ของ repo มี rules ของทั้งเกมบนเวทีและ `q_*` ของ quiz) → Publish
2. GitHub Pages deploy โฟลเดอร์นี้ให้อัตโนมัติที่ `/quiz/`
3. เปิด `quiz/host.html` → ใส่ PIN → ตั้งค่า → พิมพ์ QR

## ทดสอบในเครื่อง

```
cd quiz && npm install && cd ..
node quiz/tools/devserver.js . 8790     # http://localhost:8790/quiz/host.html?dev=1  (PIN 123456)
node quiz/tools/sim.mjs 150             # ผู้เล่นจำลอง 150 คน ตอบทุกข้อที่เปิด
```

## โควตา Firestore (แผนฟรี)

ออกแบบให้มือถือฟังเพียง 4 เอกสาร (`q_state/live`, `q_pub/current`, `q_pub/config`, `q_board/live`) ตัวนับสดอยู่ใน `q_pub/counts` ที่มีแค่จอหลักฟัง
ผู้ชม 300 คน × 9 ข้อ ใช้ประมาณ 20–30k reads และ ~3k writes ต่อรอบ (แผนฟรี: 50k reads / 20k writes ต่อวัน) — ซ้อมหลายรอบในวันเดียวกันอาจเกินได้
